# Student Portal
student portal web app with login, dashboard, profile, and settings pages.

## About
Student Portal is a lightweight web app for students to log in, view their dashboard,
manage their profile, and update settings.

## Features
- Simple login screen
- Dashboard with CGPA, courses, and deadlines
- Editable student profile
- User settings (theme, notifications, language)

## Installation
1. Clone the repository: `git clone https://github.com/Pal315/student-portal.git`
2. Open `index.html` in your browser (no build step required).

## Usage
Log in with the demo credentials shown on the login page, then use the top navigation
bar to move between Dashboard, Profile, and Settings.
